# Marketing Screenshot Candidates

This folder collects every likely Tappy marketing/App Store screenshot I found locally.

- `_all_unique/` contains one copy of each unique image, with filenames prefixed by source set.
- `source_sets/` preserves all source groups, including exact duplicates.
- `MANIFEST.tsv` lists every copied source file with dimensions, MD5, and the corresponding unique copy when applicable.

Useful sets:

- `01-previous-tappy-screenshots`: older screenshots from the original `tappy screenshots` folder.
- `02-appstore-macappstore-2880x1800`: 2880x1800 Mac App Store screenshot set.
- `03-current-upload-1440x900`: the current five screenshots used in App Store Connect.
- `04-mac-approved-1440x900`: three older approved-style Mac screenshots.
- `05-editorial-1440x900`: editorial marketing screenshots.
- `07-rendered-exports`: rendered screenshot variants, including square `.html.png` previews.
- `10-git-history-appstore-raw`: deleted raw App Store screenshots recovered from git history.
- `11-git-history-older-upload`: deleted older App Store upload screenshots recovered from git history.
